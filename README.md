# Personal Portfolio

A personal portfolio website for Yamiko Ntata, a Bachelor of Science in Computer Science student at DMI-St. John the Baptist University, Mangochi Campus, Malawi.

## Purpose

The site presents my education, technical skills, projects and career goals to employers, internship providers and collaborators. It links to each project's GitHub repository so visitors can check the code.

## Pages

- **Home:** Introduction, hero section with background photo, and a typing text animation.
- **About:** Personal introduction, education table, technical skills list, interests, career goals and contact details.
- **Projects:** Three projects with descriptions, the problems they solve, technologies used, screenshots and GitHub links.
- **Animated Concepts:** Typing text, hover effects, animated skill bars and scroll reveals.

## Technologies

- HTML5 for page structure
- CSS3 for layout (Flexbox and Grid), colours, typography, transitions, `@keyframes` animations and responsive design
- JavaScript for the typing effect, skill bar animation and scroll reveal (IntersectionObserver)
- Visual Studio Code for development
- GitHub and GitHub Pages for version control and hosting
